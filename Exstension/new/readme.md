## ✨ Apa yang Baru?

Versi ini membawa pembaruan besar dengan mengintegrasikan kekuatan AI langsung ke dalam search bar Anda!

1. **Fokus pada Gemini**: Ekstensi kini berfokus penuh pada ekosistem Google Gemini untuk pengalaman yang lebih terintegrasi.
2. **Mode Gemini Ganda**: Anda bisa menggunakan Gemini untuk chat (teks) dan analisis file, serta mode baru untuk membuat gambar (image generation).
3. **Upload File (Multimodal)**: Tanyakan apa saja tentang file yang Anda unggah (gambar, audio, video, dokumen) langsung ke Gemini.

## 🚀 Cara Menggunakan

- **Beralih Mode**: Tekan tombol `Tab` pada keyboard Anda untuk beralih antara mode **Google**, **Gemini (Teks)**, dan **Gemini (Gambar)**.
- **Mengunggah File**: Klik ikon paperclip `📎` di sebelah kiri kotak input untuk memilih file dari komputer Anda.
- **Memulai Percakapan**: Ketik pertanyaan Anda (atau biarkan kosong jika hanya ingin bertanya tentang file) dan tekan `Enter`.
- **API Key**: Saat pertama kali menggunakan mode Gemini, Anda akan diminta untuk memasukkan API Key pribadi Anda dari Google AI Studio. Key ini disimpan dengan aman di perangkat Anda.
