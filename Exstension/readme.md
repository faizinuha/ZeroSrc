## ✨ Apa yang Baru?

Versi ini membawa pembaruan besar dengan mengintegrasikan kekuatan AI langsung ke dalam search bar Anda!

1. **Dukungan OpenAI**: Selain Google dan Gemini, kini Anda bisa berinteraksi langsung dengan model AI dari OpenAI (seperti GPT-3.5 Turbo).
2. **Upload File (Multimodal)**: Sekarang Anda bisa mengunggah file (gambar, audio, video, dokumen) dan bertanya kepada AI tentang file tersebut. Fitur ini didukung penuh oleh Gemini dan untuk gambar pada model OpenAI yang kompatibel (seperti GPT-4o).
3. **UI yang Lebih Baik**: Tampilan yang disempurnakan untuk beralih mode dan melampirkan file dengan mudah.

## 🚀 Cara Menggunakan

- **Beralih Mode**: Tekan tombol `Tab` pada keyboard Anda untuk beralih antara mode pencarian **Google**, **Gemini**, dan **OpenAI**.
- **Mengunggah File**: Klik ikon paperclip `📎` di sebelah kiri kotak input untuk memilih file dari komputer Anda.
- **Memulai Percakapan**: Ketik pertanyaan Anda (atau biarkan kosong jika hanya ingin bertanya tentang file) dan tekan `Enter`.
- **API Key**: Saat pertama kali menggunakan mode Gemini atau OpenAI, Anda akan diminta untuk memasukkan API Key pribadi Anda. Key ini disimpan dengan aman di perangkat Anda dan tidak pernah dikirim ke server kami.

## Catatan Pengembangan

Fitur integrasi OpenAI pada ekstensi ini dikembangkan dengan bantuan dari **Google Gemini**.
