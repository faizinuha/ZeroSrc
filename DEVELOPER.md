~## Panduan Kontribusi ZeroSrc~

~Kami sangat senang Anda tertarik untuk berkontribusi pada ZeroSrc! Panduan ini akan membantu Anda memulai dan memastikan proses kontribusi berjalan lancar.~

~### Cara Memulai~

~1.  **Fork** repositori ini ke akun GitHub Anda.~
~2.  **Clone** repositori yang sudah di-fork ke mesin lokal Anda:~
~    ```bash~
~    git clone [https://github.com/akun-anda/ZeroSrc.git~](https://github.com/akun-anda/ZeroSrc.git~)
~    cd ZeroSrc~
~    ```~
~3.  **Buat branch baru** untuk fitur atau perbaikan bug Anda:~
~    ```bash~
~    git checkout -b nama-branch-Anda~
~    ```~

~### Standar Kode~

~* **Gaya Kode:** Ikuti gaya kode yang sudah ada dalam proyek. Jika ada linter atau formatter, pastikan Anda menjalankannya sebelum mengajukan perubahan.
* **Komentar:** Beri komentar pada kode yang kompleks.
* **Dokumentasi:** Perbarui dokumentasi yang relevan jika perubahan Anda memengaruhi cara kerja fitur.~

~### Proses Pull Request (PR)~

~1.  **Commit Perubahan Anda:** Buat commit yang jelas dan ringkas. Gunakan pesan commit yang deskriptif.~
~2.  **Push Branch Anda:**~
~    ```bash~
~    git push origin nama-branch-Anda~
~    ```~
~3.  **Buka Pull Request:** Buka Pull Request (PR) dari branch Anda ke branch `main` di repositori utama.~

~### Saat Membuka PR, Sertakan Hal Berikut:~

~* **Judul PR:** Ringkas dan deskriptif.~
~* **Deskripsi PR:** Jelaskan perubahan Anda, mengapa itu diperlukan, dan isu apa yang diselesaikannya (jika ada, tautkan dengan #nomor-isu).
* **Tangkapan Layar/GIF (opsional):** Tambahkan visual jika perubahan Anda melibatkan UI.~

~Kami akan meninjau PR Anda secepat mungkin. Terima kasih atas kontribusi Anda!~
