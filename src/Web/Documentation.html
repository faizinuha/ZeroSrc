Dokumentasi ZeroMix

Panduan Lengkap Penggunaan, Instalasi, dan Pengembangan

Apa itu ZeroMix?

ZeroMix adalah suite utilitas Windows berperforma tinggi yang dirancang untuk mempercantik dan mempercepat alur kerja Anda. Menggabungkan sistem monitoring real-time, translator otomatis, dan peluncur aplikasi cerdas.

Cepat & Ringan

Dibangun dengan .NET 9.0 untuk responsivitas maksimal tanpa membebani sistem.

Customizable

Sesuaikan hotkey, tema, dan perilaku aplikasi sesuai kebutuhan Anda.

Open Source

Kode transparan dan dapat dikembangkan oleh komunitas melalui sistem Plugin Lua.

Panduan Instalasi (Multi-Method)

Pilih metode instalasi yang paling sesuai dengan kebutuhan Anda:

1. Metode CLI (PowerShell One-Liner)

Metode tercepat untuk teknisi dan power user. Cukup buka PowerShell dan jalankan perintah:

iwr -useb bit.ly/ZeroMix | iex

2. Installer Standar (.EXE)

  • Unduh file terbaru dari GitHub Release.
  • Pilih .exe (Standard Setup) untuk instalasi mudah di komputer Windows Anda.
  • Ikuti wizard instalasi hingga selesai.

3. Versi Portable (.ZIP)

Cocok untuk penggunaan di USB atau tanpa hak akses Administrator.

  • Ekstrak isi ZIP ke folder manapun.
  • Jalankan ZeroMix.exe untuk memulai.

Cara Penggunaan & Shortcut

Alt + Space

Buka Search Overlay (Aplikasi, File, dan Web).

Alt + S

Aktifkan Fake Sleep Mode (Always-On Display).

Ctrl + Space

Akses cepat ke Dashboard & System Monitor.

Anda dapat mengubah shortcut ini melalui menu Settings di Dashboard ZeroMix.

Desain & Arsitektur

ZeroMix dikembangkan dengan filosofi "Modern Glassmorphism".

  • UI Engine: WPF dengan dukungan DWM Blur-behind untuk efek kaca transparan.
  • Logic Core: Async-based C# processing untuk memastikan UI tidak pernah lag.
  • Plugin System: Integrasi MoonSharp (Lua) yang memungkinkan script eksternal berinteraksi dengan API inti ZeroMix.
