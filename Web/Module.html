Langkah-Langkah Membuat Plugin

1. Inisialisasi Plugin

Klik tombol "+" di dashboard ZeroMix, masukkan nama plugin, dan pilih opsi "Template" untuk mendapatkan kode dasar To-Do List.

2. Coding Lua

Buka folder plugin (ikon folder ) dan edit file script.lua. Gunakan fungsi CreateUI, AddButton, dan AddInput.

3. Manajemen Data

Gunakan fungsi SaveConfig('key', json_string) untuk menyimpan data secara permanen di file JSON lokal.

4. Tampilkan di Desktop

Aktifkan toggle di Dashboard atau buat Shortcut Desktop untuk akses cepat jagoan plugin buatan Kakak!
