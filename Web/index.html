🔍 Saran Cerdas

Buat hotkey kustom untuk aplikasi favorit. Tersimpan di %AppData% dan aktif tanpa restart.

Ikon tray dengan Dashboard CPU/RAM dan tombol pembersih file sementara.

🌐 Browser Extension

Popup pencarian cepat di Chrome/Edge/Opera dengan saran Google. Kirim Feedback

📥 Cara Install

💻 Desktop App

  1. Download ZeroMix-Setup.exe
  2. Jalankan installer dan ikuti langkah-langkahnya
  3. Selesai! ZeroMix siap dipakai di PC

🌐 Browser Extension

  1. Buka browser (Chrome/Edge/Opera)
  2. Aktifkan Developer Mode
  3. Pilih Load unpacked dan arahkan ke folder /Web
  4. Extension ZeroMix siap digunakan
