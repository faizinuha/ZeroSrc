📥 Cara Install

💻 Desktop App

  1. Download ZeroSrc-Setup.exe
  2. Jalankan installer dan ikuti langkah-langkahnya
  3. Selesai! ZeroMix siap dipakai di PC

🌐 Browser Extension

  1. Buka browser (Chrome/Edge/Opera)
  2. Aktifkan Developer Mode
  3. Pilih Load unpacked dan arahkan ke folder /Web
  4. Extension ZeroMix siap digunakan
