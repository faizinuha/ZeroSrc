Tentang ZeroMix

Smart Launcher untuk Produktivitas Maksimal

Apa Itu ZeroMix?

ZeroMix adalah smart launcher untuk Windows dengan overlay pencarian bergaya Spotlight yang dibuka dengan hotkey global Alt+Space. Aplikasi ini memadukan saran aplikasi lokal dari Start Menu dan Desktop dengan saran Google secara real-time, sehingga Anda bisa meluncurkan aplikasi atau langsung mencari di web hanya dengan keyboard.

Dengan ZeroMix, Anda dapat membuat custom shortcut untuk membuka aplikasi apa pun dengan lebih cepat. Semua konfigurasi disimpan aman di %AppData%/ZeroMix dan dapat diterapkan tanpa perlu restart aplikasi. Pengalaman yang mulus dan responsif membuat produktivitas Anda meningkat drastis.

Aplikasi berjalan di system tray dan menyediakan Dashboard ringan untuk memantau penggunaan CPU/RAM serta melakukan pembersihan file sementara. Fitur pembaruan otomatis memeriksa rilis terbaru di GitHub, mengunduh installer, dan menjalankannya secara senyap ketika Anda memberikan persetujuan.

ZeroMix juga hadir sebagai browser extension (Chrome/Edge/Opera) dengan pop-up pencarian cepat dan saran Google, sehingga pengalaman pencarian tetap konsisten di desktop dan browser Anda.

⚙️ Spesifikasi Teknis

Sistem Operasi

  • Windows 10/11 - Kompatibel penuh
  • Prosesor: Intel(R) Core(TM) i3 @ 1.90GHz atau lebih
  • RAM: Minimal 8GB
  • Storage: ~50MB untuk instalasi

Browser (untuk Extension)

  • Google Chrome (Versi 90+)
  • Microsoft Edge (Versi 90+)
  • Opera (Versi 76+)

Teknologi

  • Backend: C# .NET 9.0
  • Frontend: WPF (Windows Presentation Foundation)
  • Extension: JavaScript, HTML5, CSS3
  • Repository: GitHub (Open Source)
